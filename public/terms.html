1. About the service

The Firewall Mindset DNS Leak Test is a diagnostic tool designed to help users inspect which DNS resolvers are being used by their internet connection.

The service generates temporary randomized DNS hostnames and records which DNS resolvers contact our authoritative DNS server.

The resulting resolver information may be enriched with ISP, organization, autonomous system, country, and approximate location information.

2. Informational purpose

The DNS Leak Test is provided for informational, educational, troubleshooting, and diagnostic purposes.

Test results should not be treated as a complete security audit, guarantee of privacy, guarantee of anonymity, or certification that a VPN or network configuration is secure.

DNS behavior can be affected by operating systems, browsers, VPN software, DNS-over-HTTPS, DNS-over-TLS, network providers, caching, proxies, enterprise networks, and other infrastructure.
