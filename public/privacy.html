2. What information is processed?

The service processes only the technical information needed to perform the DNS leak test, protect the service from abuse, and present the results.

Visitor IP address

Your connection IP address may be processed by the HTTP server for security purposes, including rate limiting and abuse prevention.

DNS resolver IP addresses

When you run a DNS leak test, DNS resolvers used by your connection contact our authoritative DNS server.

The IP addresses of those DNS resolvers are recorded temporarily so they can be displayed as part of the test result.

Random test identifiers

Each test is assigned a random temporary identifier. Individual DNS probes also use randomly generated identifiers.

These identifiers are used to associate incoming DNS queries with the correct test session and to reduce interference from DNS caching.

DNS query information

The service processes DNS queries directed at the temporary hostnames generated specifically for the DNS leak test.

Network information

Resolver IP addresses may be enriched with publicly available network information such as:

  • Internet service provider
  • Network organization
  • Autonomous system information
  • Country
  • Approximate city

Technical server logs

Infrastructure components such as the web server, reverse proxy, operating system, or hosting provider may create limited technical logs for security, troubleshooting, and service reliability.

We do not intentionally log every DNS probe at the application level.

3. Why is this information processed?

Technical information is processed for the following purposes:

  • Performing the DNS leak test requested by the user
  • Determining which DNS resolvers contacted our authoritative DNS server
  • Displaying ISP, network organization, and approximate location information about detected DNS resolvers
  • Preventing automated abuse, excessive requests, and denial of service attempts
  • Maintaining the security and reliability of the service
  • Troubleshooting technical failures

4. How long is information retained?

DNS leak test data is designed to be temporary.

Test sessions

Test sessions are currently stored in server memory for approximately:

180 seconds

After expiration, the session and its recorded resolver information are automatically removed from the application's in-memory session store.

IP enrichment cache

Network enrichment results may currently be cached in memory for up to:

1 hour

This cache exists to reduce unnecessary requests to third-party network information services.

Rate limiting data

Temporary IP-based rate limiting information is stored in memory for short periods and is automatically removed when it is no longer needed.

Infrastructure logs

Reverse proxy, system, hosting, and security logs may have different retention periods depending on infrastructure configuration.

7. Automated decision-making

The service does not make legal or similarly significant automated decisions about users.

DNS resolver information is presented for informational and diagnostic purposes.

The service does not automatically guarantee that a VPN is secure or insecure based solely on the detected resolver list.

8. Data security

Reasonable technical safeguards are used to reduce unnecessary data exposure and abuse.

These safeguards may include:

  • Short-lived in-memory test sessions
  • Random cryptographic test identifiers
  • HTTP request rate limiting
  • Limits on active sessions
  • Limits on the number of DNS resolvers stored per session
  • Restricted backend network exposure
  • Reverse proxy protections
  • Controlled DNS responses
  • No recursive DNS resolution

No internet-based service can guarantee absolute security.
