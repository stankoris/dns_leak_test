Privacy Notice

This page is a technical template and should be reviewed with the site operator's legal/privacy requirements before public production use.

Data processed by the test

The service temporarily processes the IP addresses of DNS resolvers that contact the authoritative DNS test server, along with a short-lived random test identifier and query count.

Purpose

The data is used only to perform the requested DNS leak test and display the detected resolver information to the user.

Retention

Test sessions are stored in application memory only and expire automatically after the configured session TTL. Restarting the service also clears in-memory sessions.

Location and ISP enrichment

If local IP databases are configured, resolver IP addresses may be matched locally to provider and location metadata. This build does not send resolver IPs to a third-party geolocation API.
